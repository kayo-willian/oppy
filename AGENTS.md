# Oppy working agreements

- Implement only the authorized phase. Keep this independent personal project simple.
- The project idea, requirements and direction belong to the owner. Codex assists with implementation.
- Keep credentials, personal data, local databases and real environment files out of Git and logs.
- Write code, internal technical documentation, commits and pull requests in English. Maintain Brazilian Portuguese translations of technical and community documents under `pt-BR/`, with reciprocal links and synchronized content. Project-created public issues and issue templates are bilingual (English and Brazilian Portuguese); contributors may use either language in issues. Preserve existing Portuguese runtime messages unless a change is authorized.
- Follow CONTRIBUTING.md and SECURITY.md. Discuss new sources and dependencies before implementation; verify access conditions. Keep raw diagnostic snapshots, credentials and local databases out of public reports.
- Keep automated tests offline. Use external sources only within their access limits and with authorization.
- Verify changes through their normal entry points. Report actual results and untested behavior.
- Use a dedicated branch for authorized changes. Open pull requests when requested. Leave merges to the owner.
